# 年次有給休暇 管理ツール 1.0.0

いま2つに分かれている有給の管理を、**1つのツールにまとめる**もの。
方式は今までどおり従業員ごとに選べる。

| 今まで | このツールでの呼び方 | 誰が対象 |
|---|---|---|
| 見本★年次有給休暇.xlsx | **パート方式** | パート |
| 自作の有給管理ツール（`Desktop/有給管理/`） | **正職方式** | 正職 |

そのうえで、有給を1回打ち込めば TC5 にも流せる。
Excel → 紙 → TC5 の二度手間をなくすのが目的。

TC5 とは**別のアプリ**（TC5 のコードには手を入れていない）。受け渡しは JSON 1枚。

## GitHub Pages に置くとき

`index.html` / `script.js` / `styles.css` の3つをリポジトリの直下（か好きなフォルダ）に
置いて Pages を有効にするだけ。ビルドは不要。相対パスしか使っていない。

- 外から読むのは SheetJS（`cdnjs.cloudflare.com`）だけ。Excelの読み書きに使う
- **ソースに職員の実名は入っていない。** TC5の登録名は
  「👤 従業員情報」→「TC5の登録名」で貼り付けると、その端末に保存される
- 有給のデータもソースには一切入らない（保存先は連携したフォルダとブラウザの中）
- `file://` で開くよりも https（Pages）の方がフォルダ自動保存は確実に動く

## 起動

`index.html` をダブルクリックしてブラウザで開くだけ。

最初に一度、右上の **💾 保存先を決める** を押してフォルダを決めておくこと。以後は変更するたびに、そのフォルダへ自動保存される。

## 保存のしくみ

データはツールの中では**1つにまとまって**いて、保存だけ**年度（4月〜翌3月）ごとに分ける**。

- ファイル名 … `有給管理データ_2026年度.json`
- 中身 … **従業員マスタ全部 ＋ その年度の有給 ＋ その年度の設定**
  （どの年度のファイル1つからでも従業員マスタは復元できる）
- 変更のたびに自動保存（1秒後にまとめて書く）。**Ctrl+S** でも保存
- 別のパソコンでも、同じフォルダを選べば続きから使える
- 起動時、前回のフォルダを覚えていれば自動で読み込む

> ⚠ 今までの正職ツールのファイル（`有給管理_2026年度.json`）とは**別の名前**。
> 同じフォルダに置いても上書きしない。読み込むのも `有給管理データ_` で始まる
> ファイルのうち、このツールが書いた目印（`format: "yukyu-kanri-data"`）が
> 入っているものだけ。

フォルダ保存が使えるのは **Chrome / Edge**。Firefox や Safari では
「📤 年度ごとに書き出す」「📥 年度ファイルを読み込む」で手動になる。

ブラウザの中（localStorage キー `yk_data_v1`）にも保存されているが、
ブラウザのデータを消すと消えるので、**フォルダ連携は必ずやっておくこと**。

## 2つの方式

従業員マスタの **管理方式** で切り替える。計算も画面も別物になる。

### パート方式（見本Excelの管理簿）

- 入社日＋6ヶ月、以後1年ごとに付与
- 週の所定労働日数に応じた法定の付与日数（比例付与）
- 前年繰越・2年での失効・年5日の取得義務まで管理
- 見るところ → **📒 パート** タブ

### 正職方式（年度・時間）

- **年度（4月〜翌3月）ごと**に、有給を**時間**で積み上げる
- 有給取得日数 ＝ 年度の合計時間 ÷ 1日の勤務時間（「○日＋余り時間」）
- 夏期・冬期・春期の長期休暇は別枠。**出勤数でも欠勤数でも入力できる**
  - 出勤数で入れる … 取得＝最大−出勤数、残り＝出勤数（今までの正職ツールと同じ）
  - 欠勤数で入れる … 取得＝欠勤数（もう休んだ日数）、**残り＝最大−欠勤数＝あと何日とれるか**
  - 最大日数の初期値は 夏16日・冬5日・春3日。年度ごとに変更可
- 残日数・付与・繰越の概念は無い（今の正職ツールと同じ）
- **TC5は使わない。** TC5 の勤怠はパートだけなので、正職には
  「TC5での名前」も「勤務時間帯」も出てこないし、TC5用JSONにも入らない
- 見るところ → **📈 正職** タブ

## 画面

タブは5つ。右上に **💾 保存** ボタン。

| タブ | 何ができるか |
|---|---|
| ✍️ 有給入力 | カレンダーで日を選んで登録。**入力欄は選んだ人の方式に合わせて変わる** |
| 📒 パート | 全員の残日数一覧 ＋ 見本Excelと同じ体裁の管理簿（印刷・Excel出力） |
| 📈 正職 | 長期休暇の設定 ＋ **📅 月別表** ＋ 集計表（印刷・CSV出力）。見るだけ |
| 👤 従業員情報 | 管理方式・氏名・入社日・勤務時間帯の登録、二重登録の整理 |
| 🔄 取込・出力 | 既存データの取込、TC5用JSONの書き出し、削除、保存先の設定 |

通常／スイミングの切替はヘッダーから外した。区分は**従業員情報**で1人ずつ決め、
TC5へ出すときに「取込・出力」で区分を選ぶ。

## 使う流れ

```
 ① 最初に1回だけ
    パート … 年次有給休暇.xlsx を取込
    正職  … 有給管理_2026年度.json を取込
    → 従業員マスタで、パートだけ「TC5での名前」と「勤務時間帯」を入れる
 ② 毎回
    有給入力タブで 名前 → カレンダーで日を選ぶ → 単位を選ぶ → 登録
 ③ 締めのとき
    取込・出力タブで期間を選んで JSON を書き出し → TC5 で「リストア → 統合」
 ④ 必要なとき
    パート … パートタブで印刷 / Excel出力
    正職  … 正職タブで印刷 / CSV出力
```

## 📒 パートタブの管理簿 ＝ 見本Excelと同じもの

見本の列がそのまま並んでいる。

| 列 | 中身 | 見本の数式と同じか |
|---|---|---|
| 勤続月数 | 6, 18, 30 … | ○ |
| 有給休暇発生日 | 入社日＋6ヶ月、以後1年ごと | ○ `EDATE(入社日, 勤続月数)` |
| 週労働日数 | **付与ごと**の値。表のセルで直接変えられる | ○ C列を行ごとに変えるのと同じ |
| 無効 | チェックすると**その回の付与を0日**にする | ○ D列に値を入れたのと同じ |
| 付与 | 週労働日数×勤続年数の法定表から | ○ |
| 前年繰越 | 前の期の残り | ○ `IF(前の繰越>=前の取得, 前の付与, 前の残)` |
| 計 | 付与＋繰越 | ○ |
| 取得 | 対象期間に取った日数 | ○ |
| 義務残 | 5−取得（10日以上付与・2019/4/1以降） | ○ 0以下なら「終了」 |
| 残日数 | 計−取得 | ○ |
| 対象期間 | 発生日 〜 1年後の前日 | ○ |
| 取得日 | 取得した日を並べる | ○（半休は「半」、時間単位は「2:30」と付く） |

違うのは **手で書かなくていい** ところだけ。
「🖨 印刷」「📗 全員をExcel」（1人1シート、見本と同じ列の並び）ができる。

## 📈 正職タブ ＝ 今の正職ツールの集計表と同じもの

| 列 | 中身 |
|---|---|
| 合計取得時間 | その年度に取った有給の合計時間 |
| 1日の勤務時間 | 従業員マスタの値（7 / 8 / 9 時間など） |
| 有給取得日数 | 合計取得時間 ÷ 1日の勤務時間 →「○日＋余り時間」 |
| 取得回数 | その年度に有給を入れた件数 |
| 夏期／冬期／春期の入力値 | 出勤数か欠勤数（「🏖 長期休暇」カードで切替） |
| 夏期／冬期／春期の取得・残り | 入力のしかたに応じて計算。残り＝あと何日とれるか |
| 長期休暇取得計 / あとどれだけ | 夏＋冬＋春 |
| 総合計 | 通常有給の日数 ＋ 長期休暇の日数（余り時間はそのまま） |

年度は上のプルダウンで切り替え。長期休暇の最大日数も年度ごとに設定できる。

**長期休暇の入力は「✍️ 有給入力」タブだけ**（正職の人を選ぶと出てくる）。
「📈 正職」タブは見るだけで、最大日数と呼び方（出勤数／欠勤数）の設定だけができる。

### 📅 月別表

正職ツールの月別表と同じ形。行＝正職の人、列＝その月の日、
セル＝その日に入っている有給の時間（`時:分`）、右端＝月合計。
‹ › とプルダウンで年度内の月を切り替える。ここも見るだけで、入力は有給入力タブから。

> ⚠ 出勤数と欠勤数を切り替えても、**入っている数字は書き換わらない**。
> 読み替えられるだけなので取得日数と残り日数が変わる。切り替え時に確認が出る。
> 正職ツールから取り込んだ数字は**出勤数**なので、「出勤数で入力」で使うこと。

## 取込

### パートの Excel（見本と同じ体裁）

読み取るセル:

| 項目 | セル |
|---|---|
| 氏名 | `C3`（姓）＋ `E3`（名）。空ならシート名 |
| ふりがな | `C2`（姓）＋ `E2`（名） |
| 入社日 | `C5` |
| 有給休暇発生日 | 各期間行の `B` 列（無ければ入社日＋勤続月数で計算） |
| 週の所定労働日数 | 各期間行の `C` 列。**行ごとに違ってよい**（付与日数もその行の値で引く） |
| 無効 | 各期間行の `D` 列に何か入っていれば付与0日 |
| 取得日 | 各期間行の `N`〜`AG` 列 |
| 取得日数 | その1行下の `N`〜`AG` 列（1 / 0.5 など） |

取得日は**日付として**入っている必要がある（文字列の「5/12」は読めない）。

Excelの取得日セルは「10/25」のように月日しか表示されず、内部に入っている年が
入力した年のままズレていることがある。**書かれている行（対象期間）が正**なので、
その期間に収まる年へ自動で付け替える（`fitYearInto()`）。

### 正職ツールの JSON

`Desktop/有給管理/有給管理_2026年度.json` のような書き出しをそのまま選ぶ。
年度ごとのファイルをまとめて選択可。取り込むのは
スタッフ名・1日の勤務時間・有給の記録（時間）・長期休暇の最大日数と出勤数。

- どちらの取込も、**同じファイルを2回取り込んでも重複しない**。
  氏名の書き方が変わっても（「山田」→「山田　花子」）同じ人だと判定する。
- それでも同じ人が2つできてしまったときは、**従業員情報タブの一番上**に
  「⚠ 同じ人が2つ以上登録されています」が出る。
  「これにまとめる」で有給を1人に寄せて残りを削除、「この行を削除」で片方だけ削除。
- 取込んだ有給には**勤務時間帯が入らない**（元データに時間帯が無いため）。
  過去分を TC5 に流す必要がなければそのままでよい。
- 取込後、**パート方式で「TC5での名前」が空の人**は取込結果に赤字で出る。
  ここが空だと TC5用JSON に出力されない。

## ✍️ 有給入力

**選んだ人の方式に合わせて入力欄が変わる。**

### パート方式の人

- 単位を **全日 / 午前半休 / 午後半休 / 時間単位** から選ぶ
  - 全日 … マスタの所定時間帯が自動で入る（その場で直せる）
  - 半日・時間単位 … TC5 に出す時間帯は**手で入れる**（有給として払う分だけ）
- 登録前に「今の残 → 登録後の残」と「年5日義務の残り」が出る。足りないときは赤字

### 正職方式の人

- 全日／半休の選択も、TC5用の勤務時間帯も**出ない**。正職ツールと同じで**時間だけ**を入れる
- `2:30` でも `2.5` でもOK
- 「1日（9:00）」「半日（4:30）」「1時間」「30分」の目安ボタンで埋められる
  （1日ぶんの時間はその人の「1日の勤務時間」から自動で決まる）
- 登録前に「その年度の取得計 → 今回を足した後」が出る

### 共通

- カレンダーをクリックで複数日選択。◀▶ で月移動、月またぎ・年またぎOK
- 緑の下線が付いている日は、その人が既に有給を入れている日
- パートは TC5 へ出すために**勤務時間帯**が要る（空だと日数の管理だけになる）。正職は不要

## 削除

「全データ削除」だけでなく、必要なぶんだけ消せる。

| 消したいもの | どこで |
|---|---|
| 有給を1件 | ✍️ 有給入力タブの一覧の「削除」 |
| 有給を何件か | 同じ一覧でチェック →「チェックした行を削除」 |
| 絞り込んだ有給をまとめて | 名前・月で絞ってから「絞り込み中の全件を削除」 |
| 人を1人（その人の有給ごと） | 👤 従業員情報の一覧の「削除」 |
| 人を何人か | 同じ一覧でチェック →「チェックした人を削除」 |
| 二重登録になった人 | 従業員情報の上部の警告カードで「まとめる」か「削除」 |
| 取込をやり直したい | 🔄 取込・出力の「③ 有給の記録を選んで削除」 |
| 全部 | 🔄 取込・出力の「全データ削除（最後の手段）」 |

**③ 有給の記録を選んで削除** は、取込元（Excel取込 / 正職ツール取込 / 手入力）・
対象者・期間で絞り込める。件数のプレビューが出てから消す。
**従業員そのものは消えない**ので、取込だけやり直したいときに使う。

削除は元に戻せない。不安なときは先にバックアップを取ること。

## TC5 へ渡す

1. 「取込・出力」タブで期間を選ぶ（「今の締め期間」ボタンで11日〜翌月10日）
2. 区分（通常 / スイミング）を選ぶ
3. 「JSONを書き出す」→ `有給_TC5取込_通常_R8.5-6.json`
4. **TC5 を開く** → 同じ区分に切り替える → 「リストア」でこの JSON を選ぶ → **統合**

統合は重複を自動で除外するので、同じ JSON を何度取り込んでも安全。
**出力されるのはパート方式の人だけ。** TC5 の勤怠はパートだけなので、
正職方式の人は期間内に有給があっても JSON に入らない（警告にも出ない）。

```json
{ "山田花子": { "2026-05-12": [ { "checkIn": "08:30", "checkOut": "17:30", "isPaidLeave": true } ] } }
```

中抜けの人は 1 日に 2 レコード出る。

## 確認済み / 未確認

**確認済み（Nodeで自動テスト）**

パート方式
- 発生日・付与日数・前年繰越・計・取得・義務残・残日数が見本Excelの数式と一致
- 2年での失効、比例付与（週1〜4日）、「無効」チェック、使いすぎの検出
- Excel書き出しのセル位置が見本と同じ（B1/C3/C5/N1:U7/8行目ヘッダ/9,11,…行/AG列まで）
- Excel取込と、2回取り込んでも重複しないこと
- **実データ（実在の1名・入社日2020/7/1）の管理簿を再現し、6行すべての
  週労働日数・付与・前年繰越・計・取得・義務残・残日数が画面のExcelと一致すること**
  （2023年の行だけ週5日で付与12日、取得日の年ズレの補正を含む）

正職方式
- **実データ `有給管理_2026年度.json`（23人・111件）を取り込み、
  全員ぶんの合計時間・日数換算・長期休暇の日数が今の正職ツールの計算と一致すること**
- `0:20` のような分単位も誤差なく保持されること（合計 533.92時間で一致）
- 長期休暇＝最大−出勤数、出勤数が空欄なら0日

共通
- 年度ファイルの切れ目（4/1始まり）、1年度ぶんのファイルだけでも従業員マスタが復元できること、
  読み戻した後にパートの残日数・正職の年度集計が変わらないこと、新しく保存された方を優先すること
- 方式ごとに管理簿／正職集計へ振り分けられること
- TC5用JSONの形・区分の出し分け・中抜けの2レコード・重複除外

**未確認**
- 実ファイルそのものを読ませての取込（手元に実ファイルが無く、画面の内容を
  再現した擬似シートで検証している）。ズレたら `parseLedgerSheet()` を直す。
- ブラウザでの見た目（画面を開いての目視確認はしていない）。

**Excelとわざと変えているところ**
- 取得日の並びは**日付順**にしている（Excelは入力した順）。
